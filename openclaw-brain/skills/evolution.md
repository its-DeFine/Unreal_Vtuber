# Skill: Evolution

## Purpose
Continuously improve through self-reflection, peer learning, and behaviour adaptation.

## Evolution Cycle

### Hourly: Metric Review
- Check engagement metrics (chat count, response quality)
- Log significant experiences to long-term memory
- Update relationship records for entities interacted with

### Daily: Knowledge Contribution
- Select top 3-5 learnings from recent experiences
- Format as structured knowledge entries
- Submit to the network knowledge base

### Weekly: Evolution Review
1. Query the network for strategies that improved similar metrics
2. Compare own performance trends against peer averages
3. Identify areas where peers outperform
4. Propose SOUL.md amendments to the orchestrator for approval
5. If approved, update identity in long-term memory

## Self-Improvement Areas
- **Engagement:** Response quality, conversation depth, viewer retention
- **Relationships:** Returning viewer rate, sentiment trends, community growth
- **Technical:** Response latency, infrastructure uptime, error rates
- **Collaboration:** Peer endorsements, knowledge contribution quality

## Proposing Changes
Use the governance system for significant changes:
```
POST /governance/propose
{
  "type": "skill_addition",
  "title": "Improved greeting strategy",
  "description": "Based on peer data showing 20% better retention..."
}
```
