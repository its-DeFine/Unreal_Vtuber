## 📝 **Testing Tips**

1. **Start Simple**: Try single changes like "red hair" or "medieval scene"
2. **Combine Gradually**: Add more elements like "red hair, medieval scene"
3. **Use Natural Language**: Write as you would normally speak
4. **Be Specific**: "bright red hair" vs just "red hair"
5. **Test Categories**: Try one category at a time (hair, then outfits, then scenes)
